# Contribution evidence

Store each milestone's contribution declaration (from the TeamworkContribution.xlsx template) and the GitHub contribution screenshots here.

To collect GitHub stats, the repo must be public, but publish it no earlier than 24 hours before the deadline (TW-E02). Then take screenshots of Insights > Contributors. If a GitHub username doesn't contain the member's first and last name, the README team table maps it to their full name (TW-E01).
